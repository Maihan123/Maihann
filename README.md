# Maihan – ساخت APK اندروید

## مراحل (فقط یک بار کلیک، بدون نصب چیزی روی کامپیوتر)
1. یک حساب رایگان در github.com بساز.
2. یک Repository **Public** جدید بساز (برای Release رایگان و بدون محدودیت).
3. کل محتویات این پوشه (شامل `app_files`، `.github`) را در Repository آپلود کن و Commit بزن.
   - پوشه `.github` پنهان است؛ اگر آپلود نشد، در ویندوز نمایش فایل‌های پنهان را روشن کن.
4. به تب **Actions** برو، اگر پرسید فعال‌سازی را بزن، سپس **Build Android APK** > **Run workflow**.
5. ۵ تا ۱۰ دقیقه صبر کن. وقتی سبز شد:
   - تب **Releases** (در صفحه اصلی Repository) را باز کن.
   - فایل `app-release.apk` را دانلود کن. این لینک مستقیم دانلود است.

## نصب روی اندروید
1. فایل APK را روی گوشی دانلود کن (از مرورگر Chrome).
2. فایل را باز کن. اگر گفت «نصب از منابع ناشناس مجاز نیست»، آن را برای مرورگر فعال کن و دوباره باز کن.
3. **نصب** را بزن. آیکون Maihan روی گوشی ساخته می‌شود و دائمی است (بدون محدودیت ۷ روز).

## محدودیت‌های این نسخه
- داده‌ها داخل همان گوشی ذخیره می‌شوند و بین گوشی‌ها همگام نمی‌شوند. اگر برنامه را حذف کنی، داده‌ها پاک می‌شوند.
- چاپ فاکتور، اسکن بارکد با دوربین و برش لوگو در این نسخه نیستند.
- این کد تاکنون روی گوشی واقعی تست نشده. اگر Build قرمز شد یا برنامه در اجرا خطا داد، لاگ خطا یا توضیح مشکل را برایم بفرست.
